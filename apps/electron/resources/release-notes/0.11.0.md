# v0.11.0 — Projects, Kanban, Zed, and agent workflows

## ⭐ Projects

Workspaces now have first-class Projects: named collections of sessions, assets, and context stored at `{workspaceRootPath}/projects/{slug}/`. Bind a session to a project and it inherits the project's working directory and gets a `<project_context>` block injected into its system prompt — including the project's asset manifest and a size-capped `MEMORY.md`.

- **Projects panel & info page** — a `ProjectsListPanel` in the navigator and a `ProjectInfoPage` with Sessions / Assets / Settings tabs; assign sessions from the session menu. (`f2eb9542`, `95bc761e`, `423ff362`)
- **Project-aware session list** — group and filter sessions by project. (`0ad7189e`)
- **Per-project accent color** — with an appearance-treatment toggle; workspaces got avatars and a rebuilt color picker along the way. (`2b2d64bd`, `481851f8`)
- **Live binding + context injection** — binding events update the UI live; asset manifest and project memory flow into every bound session. (`7d540944`, `742a2761`)

## ⭐ Kanban Task Board — Beta

A new board view turns a workspace's sessions and tasks into draggable cards over per-project, editable columns. Under it sits a durable Tasks system: tasks live independently of chat, can be edited, re-run, and decomposed into dependency DAGs that a Conductor orchestrator executes over child sessions.

- **The board** — add, rename, recolor, and reorder columns per project; columns can carry a drop status, so moving a card can transition the underlying session status. (`e6f5ea5b`, `5ae740b7`, `82a661f4`, `fd9c0f04`, `854a9860`, `aa9d581e`)
- **Tasks** — a dedicated task editor with create/edit modes, results, labels, acceptance criteria, create-only vs. create-then-run flows, run-from-tile, and inherited project working directories. (`9a608cc3`, `7c7eb49c`, `476a0c21`, `36b978f0`)
- **Subtasks & DAGs** — `task.yaml` DAGs spawn and supervise child sessions with dependency-ordered execution, durable resume, and subtask progress. (`ea814eba`, `5702ea6b`, `36b978f0`, `b03a9357`, `937f0ff3`)
- **Repair loop** — when a task output does not meet acceptance criteria, a repair pass re-checks and dispatches fixes. (`36b978f0`)

> **Beta notice:** the Kanban board and Tasks, including Conductor DAG runs, ship as beta. Board behavior and task spec formats may still change.

## Features

- **Background agents stay alive across turns** — background subagents are no longer killed when the spawning turn ends. A persistent query keeps the session alive; when a background agent finishes while idle, the session wakes and presents the result. Set `CRAFT_KEEP_BG_AGENTS_ALIVE=0` to opt out. (`32072bca`, `c0a726a6`, `c4201dd0`, `5e7490ae`)
- **Zed External Agent integration** — Added `craft-cli acp`, a Zed-compatible Agent Client Protocol server for running Craft Agent inside Zed as an External Agent. Includes session binding/import/load/resume and helper slash commands such as `/craft`, `/bind`, `/sources`, `/skills`, `/use-source`, and `/use-skill`.
- **Agent Profiles and delegated agents** — Added reusable agent presets, profile management, run activity, `@agent` delegation into non-blocking child sessions, cancellation, follow-up replies, and hidden-by-default task sessions.
- **Plugins hub and TAPD requirement workflow** — Added a Plugins sidebar entry with TAPD requirement import, local requirement caching, requirement detail pages, linked session groups, comments, execution logs, and requirement-scoped agent runs.
- **Agent Store MVP** — Added initial browsing and installation for agent packages with manifest, installer, receipt handling, and installer tests.
- **Session organization and remote workflows** — Added session board workflows, session groups, project label quick selectors, usage stats, SSH remote session profiles, and remote folder picking improvements.
- **CLI chat workflows** — Added an interactive CLI chat REPL bound to a Craft session, attachment support, keepalive/reconnect handling, picker fixes, and REPL-created chat sessions.

- **Sidebar label overflow** — very long session-label names now truncate instead of blowing out the session list. (`98d29930`)
- **Zed ACP compatibility fixes** — fixed `session/load`, mode updates, history import, historical session workspace selection, and slash-command advertisement.
- **Deep links and focused windows** — restored internal deeplink routing for local windows, new windows, plugin routes, and focused session windows.
- **Agent Profile persistence and source saving** — registered Agent Profile RPC channels and repaired profile dialog/source-saving flows.
- **Recent-history loading** — chat pages now load only the most recent three user rounds by default and fetch earlier rounds on scroll-up.

## Breaking Changes

- None. Background-agent keep-alive changes default behavior, but can be disabled with `CRAFT_KEEP_BG_AGENTS_ALIVE=0`.
