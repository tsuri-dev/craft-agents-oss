# v0.11.0 — Zed, WeChat, and agent workflows

## Features

- **Zed External Agent integration** — Added `craft-cli acp`, a Zed-compatible Agent Client Protocol server for running Craft Agent inside Zed as an External Agent. The adapter creates Craft sessions with a `zed` label, keeps Zed's project `cwd` as the session working directory, defaults to the active/configured Craft workspace, attaches to the already-running Craft backend through `.server.json`, streams prompt/tool updates over JSON-RPC, supports Explore/Ask/Execute mode updates, and exposes Zed Thread History import/load/resume for existing Craft sessions. Zed helper commands are advertised as ACP slash commands, including `/craft` to open the same session in a focused Craft Agent window, `/sources`, `/skills`, `/use-source`, and `/use-skill`; Zed selection context now preserves file paths, line ranges, symbols, and columns when forwarded to Craft. (`b8f2de48`, `f6ec2227`, `6a11ae41`, `b926105c`, `8c73c771`)
- **WeChat messaging adapter** — Added a Tencent iLink-based WeChat adapter to the messaging gateway, including QR-login account setup, inbound/outbound text and media handling, CDN upload/download helpers, session guards, sync-buffer storage, redacted adapter logging, a WeChat connect dialog, platform icons, renderer formatting, and pending-sender persistence so conversations can continue reliably after reconnects. (`44824ace`, `2552162b`)
- **Agent Profiles and delegated agents** — Added the Agents sidebar destination and a full profile management surface for reusable agent presets: create/rename/edit profiles, configure Explore/Ask/Execute execution mode, edit profile instructions, environment variables, skills, and sources, view run activity, and delegate `@agent` mentions into non-blocking child sessions with AgentRun manifests, transcript logs, cancellation, follow-up replies, and hidden-by-default task sessions. (`9ff336f2`, `54f54894`, `8483e213`, `f075a5ff`, `cfe0b55b`, `ea2fca57`, `39edfcc4`)
- **Plugins hub and TAPD requirement workflow** — Added a Codex-style Plugins sidebar entry with TAPD as the first installed plugin. TAPD supports link-only requirement import, local requirement caching, a two-column requirement detail page, local info folders for plans/handoffs/artifacts, linked session groups, seeded requirement sessions, local comments, collapsible execution logs, requirement-scoped agent runs, and dark-mode-safe TAPD detail rendering. (`de9d8f4a`, `ef6d7277`, `1c083f7e`, `d2723262`, `a0270bc8`, `2e669555`, `bc5a8d51`)
- **Agent Store MVP** — Added the initial Agent Store flow for browsing and downloading agent packages, with shared manifest/installer/receipt handling and installer tests. (`6a2ccc1f`)
- **Session organization and remote workflows** — Added session board workflows, session groups, project label quick selectors, usage stats, SSH remote session profiles, and remote folder picking improvements, giving workspaces more ways to group, launch, inspect, and continue sessions across local and remote projects. (`2f51991d`, `93226b23`, `2a494522`, `6091dcb4`, `794998d6`, `935014c5`, `39095234`)
- **CLI chat workflows** — Added an interactive CLI chat REPL bound to a Craft session, attachment support for `send --file/-f`, keepalive/reconnect handling, picker fixes, and the ability for the REPL command to create chat sessions. (`2b86b711`, `3f2af9a4`, `5b9d8ab7`, `d02032cb`)

## Improvements

- **TAPD link-only board** — Simplified the TAPD Requirement Board around full TAPD links and shared local snapshots instead of direct workspace/list refresh. TAPD-linked sessions now read from shared requirement markdown/info folders, avoid stale TAPD MCP source activation, expose snapshot context to agents, and keep linked session state refreshed without manual reloads. (`1c083f7e`, `22256b3f`, `a490734b`, `70b989f9`, `3db20278`)
- **TAPD orchestration hub polish** — Requirement details now use Multica-style property/work rows, hide empty fields, reuse the working-directory selector, auto-create short linked session groups when needed, separate user-created requirement sessions from agent execution logs, show token usage summaries, and render long agent comments in collapsible Markdown containers with copy/full-screen/open-summary actions. (`bc5a8d51`, `689f68eb`, `fa42214a`, `eeb89e55`)
- **GPT session controls** — Added a session-scoped Fast mode switch under GPT-5 Codex/ChatGPT model thinking controls while keeping Extra High mapped to the existing `xhigh` reasoning level. (`756a3853`)
- **Navigation cleanup** — Removed the experimental Stories workflow, moved Agents above Plugins and Plugins ahead of Sources, refined All Sessions project organization, and reset secondary filters when returning to All Sessions. (`d6d86799`, `d656d64c`)
- **Working directory launchers** — Added app launchers for the current working directory and restored the small “Open in VS Code” button next to the chat input's Working Directory badge. (`d6fff3ab`)
- **Build and packaging resilience** — Hardened mac packaging by staging the Pi agent server, packaging the ripgrep platform binary, falling back to local Bun during packaging, tolerating missing `node --check`, and restoring `import.meta.url` in the packaged CJS bundle. (`3e939cec`, `379cd288`, `ad3cce04`, `6131af66`, `3d472ed5`, `d6ac1d5c`)

## Bug Fixes

- **Inline mention menu layering** — Moved the chat composer's inline `@`, `/`, and `#` menus into a floating portal layer so menus stay above composer chrome and panel content after mention badge deletion or rapid retriggering. (`9ca2907f`)
- **Electron dev startup and backend reuse** — Registered preload sync IPC handlers early, sanitized inherited packaged-runtime `CRAFT_*` env vars in dev launches, made window state honor `CRAFT_CONFIG_DIR`, and let CLI ACP attach to the running backend through `.server.json` instead of starting a duplicate server that can hit `.server.lock`. (`7fb04cbe`, `f6ec2227`)
- **Zed ACP compatibility fixes** — Fixed `session/load` to return a valid `LoadSessionResponse`, emitted `currentModeId` for mode updates, broadened history import to all non-hidden current-workspace sessions, opened loaded historical sessions in their persisted Craft workspace, and advertised slash commands so Zed no longer rejects `/craft` before the agent sees it. (`406c5807`, `d1116281`, `62b22c92`, `b926105c`)
- **Deep links and focused windows** — Restored internal deeplink routing for local windows, new windows, plugin routes, and active deeplink schemes; focused session windows can now open directly from workspace handlers and `/craft` with chat input focus. (`73ece125`, `21ae8fd5`, `dcd551d9`, `7297c618`, `6a11ae41`)
- **Agent Profile persistence and source saving** — Registered Agent Profile RPC channels, repaired profile dialogs/env saving, filtered workspace skills when adding skills, and saved enabled sources through `agentProfiles:update` instead of failing on missing routes. (`42e0422d`, `40448052`, `711c89c1`, `866619c4`)
- **Markdown, status, and source rendering hardening** — Safely renders unknown Markdown HTML tags, hardens source status rendering, improves agent detail/project menus, and keeps delegated agent working-directory/context handling consistent across follow-ups. (`f975fad9`, `c4683aee`, `01f2cd98`, `63a637d1`, `fd2b6c39`)
- **TAPD reliability fixes** — Improved TAPD cache hydration, session linking, info-file refresh, local comment/run channel routing, image zoom, label editing, requirement deletion, drag sorting, and theme token usage so plugin data stays local, navigable, and visually consistent. (`eeb89e55`, `fa42214a`, `21d6a411`, `1e656599`, `c20c30fb`, `ad9b19c1`, `77943d98`)
- **WeChat pending senders** — Persisted pending sender state in the messaging gateway so WeChat messages can be correlated after reconnect/restart instead of losing reply context. (`2552162b`)
- **Messaging performance on long sessions** — Reduced overhead from the messaging gateway on busy sessions by indexing bindings by session, skipping WeChat-only transient token/tool events that never produce visible chat output, rate-limiting adapter-disconnect warnings, and making session-list messaging badges subscribe only to their own session binding state. Session switching also avoids a blank animation gap while long conversations load.
